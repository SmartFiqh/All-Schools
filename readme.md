# 📖 الجامع المختر لاراء المذاهب 

منصة لعرض ومقارنة آراء المذاهب الفقهية (السنية والشيعية والإباضية) بست لغات — للفهم والتبصر، وليست موقع إفتاء.

## المتطلبات

الاعتماد الوحيد هو مكتبة `streamlit`، ولا حاجة لأي مفتاح API أو إعداد إضافي — قاعدة البيانات (SQLite) تُنشأ تلقائياً عند أول تشغيل.

```
pip install -r requirements.txt
```

## التشغيل محلياً

```
streamlit run app.py
```

## النشر على Streamlit Community Cloud

1. ادفع (push) هذا المستودع إلى GitHub.
2. من [share.streamlit.io](https://share.streamlit.io) اختر "New app"، وحدد المستودع والفرع (branch) والملف الرئيسي `app.py`.
3. لا حاجة لأي "Secrets" — التطبيق لا يعتمد على أي خدمة خارجية.

## بنية المشروع

```
.
├── app.py             # التطبيق كاملاً (Streamlit، ملف واحد)
├── requirements.txt   # الاعتماد الوحيد: streamlit
└── README.md
```

## الميزات

- مقارنة آراء 8 مذاهب فقهية جنباً إلى جنب، بثلاثة مستويات تفصيل.
- دعم 6 لغات: العربية، الإنجليزية، الفرنسية، الفارسية، الملايوية، الأردية.
- بحث محلي (بدون إنترنت) متسامح مع اختلاف الرسم الإملائي والتشكيل في العربية.
- استيراد مسائل إضافية عبر ملف CSV (قسم للمشرفين).
- مسارد مصطلحات فقهية، قائمة دول وأئمة مذاهب، وقواعد وأصول فقهية — كل ذلك بالبيانات المدمجة في `app.py` دون أي خدمة خارجية.

## ملاحظة حول البيانات

قاعدة بيانات `fiqh.db` (SQLite) تُنشأ محلياً عند أول تشغيل ولا تُحفظ بشكل دائم على Streamlit Community Cloud (التخزين هناك مؤقت ويُعاد تعيينه عند إعادة تشغيل التطبيق). لتخزين دائم لمسائل مستوردة عبر CSV، استضف التطبيق على بيئة ذات تخزين دائم أو استخدم قاعدة بيانات خارجية.
