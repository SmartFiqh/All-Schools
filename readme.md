# 📖 بيان - مرشد الآراء الفقهية

**بيان** هو تطبيق ويب يهدف إلى تقديم آراء المذاهب الفقهية الإسلامية بأسلوب مبسط ومنظم، مع التركيز على:

- عرض آراء المذاهب السنية (المالكي، الشافعي، الحنبلي، الحنفي، الظاهري)
- عرض آراء المذاهب الشيعية (الجعفري، الزيدي)
- عرض المذهب الإباضي
- تعريف بالأئمة المؤسسين وأشهر العلماء
- خريطة المذاهب الرسمية في الدول الإسلامية
- قاموس المصطلحات الفقهية
- دعم 6 لغات (العربية، الإنجليزية، الفرنسية، الفارسية، الأردوية، الملاوية)

---
