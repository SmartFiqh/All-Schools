# الجامع المختصر لآراء المذاهب

منصة عرض ومقارنة آراء المذاهب الفقهية الإسلامية الثمانية (مالكي، شافعي، حنفي، حنبلي، ظاهري، جعفري، زيدي، إباضي) بست لغات (العربية، الإنجليزية، الفرنسية، الفارسية، الملايوية، الأردية) — **للفهم والتبصر، وليست موقع إفتاء.**

---

## كيف تُبنى الإجابة؟ (ثلاث طبقات بالترتيب)

هذا هو الجزء المهم فهمه قبل النشر. كل سؤال يمرّ عبر ثلاث طبقات، بالترتيب، وتتوقف المحاولة عند أول طبقة تنجح:

| # | الطبقة | المصدر | الموثوقية | العلامة على البطاقة |
|---|--------|--------|-----------|----------------------|
| 1 | **قاعدة البيانات الموثقة** | مسائل أدخلها/راجعها بشر يدوياً في `fiqh.db` | ✅ الأعلى — محتوى مُراجَع | بلا علامة خاصة (لون محايد) |
| 2 | **RAG (استرجاع من مراجع مرفوعة)** | نصوص فعلية رفعها مشرف (كتب/مقالات يملك حق استخدامها)، مفهرسة دلالياً | ⚠️ متوسطة — الذكاء الاصطناعي يلخّص من نص حقيقي مع استشهاد بمصدره، لكن التلخيص نفسه غير مُراجَع بشرياً | 📖 بطاقة بحدود زرقاء + اسم المصدر |
| 3 | **توليد حر بالذكاء الاصطناعي** | معرفة النموذج العامة (Gemini) بلا أي مرجع نصي فعلي خلفه | 🔴 الأدنى — قد يحتوي أخطاء واختلاق دون تحذير واضح لولا الوسم | 🤖 بطاقة بحدود ذهبية متقطعة + تحذير بارز أعلى النتائج |

**لماذا لا تُدمج الإجابات الثلاث بلا تمييز؟** لأن هذا تطبيق فقهي: عرض تخمين نموذج ذكاء اصطناعي بنفس شكل رأي مذهب موثّق يُضلّل المستخدم دون أن يقصد أحد ذلك. الوسم الواضح لكل طبقة هو ما يجعل النظام مسؤولاً، لا الدقة وحدها.

---

## طبقة RAG بالتفصيل — كيف تعمل فعلياً؟

1. **الرفع (مرة واحدة لكل مرجع):** من لوحة "📁 إدارة المراجع (RAG)" داخل التطبيق، يلصق المشرف نص مرجع (أو يرفع ملف `.txt`)، مع عنوان ووسم مذهب اختياري.
2. **التقطيع:** يُقسَّم النص تلقائياً إلى مقاطع صغيرة (~700 حرف مع تداخل 100 حرف لعدم قطع الجمل في نقاط غير مناسبة).
3. **التمثيل الرقمي (embedding):** يُحسب لكل مقطع متجه رقمي عبر `models/text-embedding-004` من Gemini، ويُخزَّن في جدول `reference_chunks` — **هذه الخطوة تُنفَّذ مرة واحدة فقط عند الرفع**، وليست في كل بحث.
4. **البحث (لكل سؤال):** يُحسب متجه رقمي للسؤال فقط (استدعاء واحد سريع لواجهة Gemini)، ثم تُقارَن رياضياً (تشابه جيب التمام، عبر NumPy) بكل المتجهات المخزَّنة — **هذه المقارنة نفسها تُنفَّذ محلياً خلال أجزاء من الثانية**، حتى مع آلاف المقاطع.
5. **التوليد المؤسَّس:** أقرب 6 مقاطع فقط تُرسَل إلى Gemini مع تعليمات صريحة: "أجب حصراً بناءً على هذه المقاطع، واستشهد برقم المصدر، وإن لم يتضمن أي مقطع رأي مذهب معين فقل ذلك صراحةً بدل الاختلاق."

**السرعة الفعلية:** خطوة الفهرسة (٣) تحدث مرة واحدة عند الرفع وقد تستغرق ثوانٍ حسب طول النص. أما زمن الإجابة على كل سؤال فهو عملياً: استدعاء واحد لحساب تمثيل السؤال + بحث رياضي فوري + استدعاء توليد واحد لـ Gemini — أي **ثوانٍ معدودة**، وليس دقائق، بغض النظر عن حجم المكتبة المرجعية.

**حدود صادقة يجب معرفتها:**
- جودة الإجابة محكومة تماماً بجودة وشمول ما رفعتَه. مرجع ناقص أو مغلوط ينتج إجابة ناقصة أو مغلوطة، بثقة ظاهرها الاستناد لمصدر.
- لا تملك أنا (Claude) أي نصوص فقهية فعلية لأزوّدك بها؛ عليك رفع نصوص تملك حق استخدامها فعلاً — احترام حقوق النشر مسؤوليتك كمشغّل للتطبيق.
- الاسترجاع الدلالي ليس مثالياً؛ قد يفوته مقطع ذو صلة لو كانت صياغة السؤال بعيدة لغوياً عن صياغة المرجع.

## الإعداد والتشغيل

### المتطلبات
```bash
pip install -r requirements.txt
```

### مفتاح Gemini API (مطلوب لطبقتي RAG والتوليد الحر — قاعدة البيانات الموثقة تعمل بدونه)
اختر إحدى الطريقتين:

**عبر `.env`** (للتشغيل المحلي):
```
GEMINI_API_KEY=your_key_here
```

**عبر `st.secrets`** (موصى به عند النشر على Streamlit Community Cloud):
أنشئ `.streamlit/secrets.toml`:
```toml
GEMINI_API_KEY = "your_key_here"
```

احصل على مفتاح مجاني من [Google AI Studio](https://aistudio.google.com/apikey).

### التشغيل
```bash
streamlit run app.py
```

بدون مفتاح API، يعمل التطبيق بالطبقة الأولى فقط (قاعدة البيانات الموثقة) ويعرض تنبيهاً واضحاً بأن الإجابة التلقائية معطّلة، بدل التعطل أو التظاهر بأن كل شيء يعمل.

## إضافة مسائل لقاعدة البيانات الموثقة (الطبقة الأعلى موثوقية)

طريقتان:
1. **يدوياً في الكود:** أضف عنصراً جديداً لقائمة `issues` داخل دالة `seed_initial_issues()` في `app.py`، بنفس بنية الأمثلة الموجودة (صلاة الجماعة، صلاة الجنازة، الربا). الفهرسة تتحقق تلقائياً من عدم التكرار عبر `title_ar`، فيمكنك تشغيل التطبيق بأمان بعد الإضافة دون حذف `fiqh.db`.
2. **عبر CSV:** من لوحة "📥 استيراد مسائل من CSV" داخل التطبيق، بنفس أعمدة الجدول (`topic, title_ar, title_en, ...`).

```
app.py              # التطبيق كاملاً (واجهة + قاعدة بيانات + RAG + توليد حر)

fiqh.db             # يُنشأ تلقائياً عند أول تشغيل (SQLite) — المسائل + مقاطع المراجع المفهرسة
.env                # (تُنشئه أنت) — مفتاح Gemini API، لا يُرفع لأي مستودع عام
```

## تنبيهات مهمة قبل النشر العام

- **راجع الترجمات مع متحدث أصلي لكل لغة** قبل النشر — مصطلحات مثل "فرض عين" مقابل "فرض كفاية" حسّاسة للمعنى، وترجمة آلية قد تُغيّره.
- **لا تنشر التطبيق للعموم دون تفعيل التمييز بين الطبقات الثلاث** الموضّح أعلاه — إخفاؤه يحوّل تخمينات الذكاء الاصطناعي إلى ما يبدو كأنه فتاوى موثقة.
- **هذا التطبيق أداة عرض ومقارنة، وليس بديلاً عن استشارة عالم مختص** لأي مسألة شخصية أو ملزمة.
